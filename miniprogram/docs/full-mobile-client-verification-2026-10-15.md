## 如何查看

1. 微信开发者工具打开 `/Users/ming/Downloads/小程序开发/yizhanchengming/miniprogram`。`project.config.json` 的 `miniprogramRoot` 为 `dist/`。
2. 运行 `npm run build:weapp` 后点击开发者工具“编译”。此命令读取 `.env.production`，当前为 `https://yzcm.site`。
3. 登录页确认服务地址，然后输入该服务的已有账号密码；开启二步验证的账号需验证码。不会自动请求微信绑定，不保存密码。
4. 本机账号库单独使用 `npm run build:weapp:sandbox`，读取 `.env.development`。本地账号和公网账号不能假定相同，手机也不能访问电脑的 `127.0.0.1`。
5. 真机前需在微信后台配置相应 request/download/upload 合法域名。客户端构建不代表这些平台配置已完成。

## 逐项验收顺序

先登录并核对个人身份，再逐个模块确认项目/任务列表与网页相同；打开同一记录比较原文、配置、提示词、图片和视频。切换项目检查旧数据不闪回；退出换账号检查旧媒体不再出现。随后才以明确的小任务验证写入、刷新读回和真正结果。生成、合成与提交可能触发费用或外部状态，不能用重复点击处理未知结果。

当前不能据此宣称“公网全功能已完全对应”或“可以直接发布”。上表列出的未移植能力和实际账号/真机验收仍是交付边界。
