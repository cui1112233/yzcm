范围：本地小程序基础系统及批量工厂四页。用户已确认规范并要求执行。未修改公网、后端、数据库、密码或API契约，未提交、推送或部署；未执行生成、上传、发布或定时业务。

## 实现

- `src/ui/tokens.ts`：深浅语义颜色、逻辑px字号与间距。每个ThemedPage根注入变量，原生导航复用颜色；运行时变量不经过Taro的设计稿尺寸换算。
- `src/ui/system.scss`：公共字体、按钮、表单、状态、卡片、图标和品牌栏；公共控件原有基础声明从app.scss移除，避免两套所有权。专用模块样式仍保留。
- `src/ui/nativeTabIcons.ts`：四个原生Tab深浅主题普通与选中态，共16张本地变体，复用原图轮廓和透明通道；保留原图。app.config设置暗色初始资源，主题变化时同步原生图标与文字。
- `src/pages/batch/mobile.scss`：合并重复声明，作品使用紧凑列表，保留选书、配置、执行与定时、添加书城、单书各栏目和合成提交入口。窄屏启动选项纵排。
- `OperationDock`：测量含安全区和换行的实际高度，增加等高占位及16px间距，窗口尺寸变化重测，卸载后不更新状态。
- 单书：页签使用按钮，资产图aspectFit可全屏查看；原文取消固定高度截断，提供16/18/20px字号；原文与分镜提示词可选择和复制。视频按元数据调整显示比例，保留原有鉴权加载、分镜同步、确认与账号边界。
- 默认不显示背景星光循环，不引入业务不需要的视差、指针跟随或时间轴。公共控件使用120ms色彩反馈，减少动效媒体条件下关闭过渡。
