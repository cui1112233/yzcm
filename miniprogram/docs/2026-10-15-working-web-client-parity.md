## 本轮已落地的明确差异

1. Fetch 刷新使用各自结果：定时失败仍展示成功读取的配置和任务，分区错误有明确来源，未知写操作结果只在任务成功刷新后解除。
2. Fetch 按网页版顺序合并全局和工作表 AI 槽位设置；显式 false 不会被全局 true 覆盖。
3. 版本配置可选择原文和 AI1–AI5，沿用原 work-form 保存契约。
4. 恢复剧本历史保留 videoTasks。结果页按分镜显示已有任务状态、查看视频、刷新状态；使用已有媒体下载服务和原生 Video。没有发起视频生成、补造结果或自动重试昂贵任务。
5. 切换历史时清空旧结果；新原文、重新提取和新生成结果不继续挂旧历史视频。下载重复点击合并，离开页面后的晚响应不能挂回播放器，错误可见。
