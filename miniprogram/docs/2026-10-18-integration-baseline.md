## 4. 真实接入的现状

- 工程已经有公网账号登录、业务服务层和真实列表读取，不能将其描述为只有静态页面。
- 构建产物中存在 `https://yzcm.site`；代码同时保留未配置时的无效域名占位符。该字符串检查不能替代对每一条真实请求的目标域名核验。
- 当前登录页 `pages/bind/index.tsx` 调用 `loginAccount`，是用户名、密码与可选 MFA 登录。
- `session.ts` 已有 `bootstrapWechatSession` 和 `bindExistingAccount`，分别指向 `/api/wechat-miniprogram/session`、`/api/wechat-miniprogram/bind`，但目前没有页面调用它们。因此微信身份登录、首次绑定不能算已接通，服务端支持情况也尚未核验。
- 既有排查中 Agent Studio 缺少有效 Cookie、批量工厂部分批次缺少 summary 状态，仍为待复核问题；不得因为其他模块能登录而宣布这些问题消失。
- 当前目录的 `dist` 约 1.8MB，宠物素材约 648KB，仅是文件系统占用，微信上传包分析和真机内存仍需实际检查。

## 5. 接入路线建议

优先建议：沿用现有公网账号登录，先完成真实业务读写链路，改动范围较小，可尽早验证用户最关心的批量工厂和水货生产。

另一条路线：微信快捷登录 → 首次绑定已有公网账号 → 后续恢复身份。体验更接近原生小程序，但必须同时验证服务端微信身份交换、绑定归属、会话失效与解绑规则，不能只改按钮。

用户已确认：先保留公网账号登录，打通业务。本阶段不接微信快捷登录，不替换后端。

接入顺序：

1. 验证目标域名、微信合法域名配置和登录会话；选定并落地登录路线。
2. 优先核验批量工厂与水货生产：入口、列表、详情、资源读取、空/错误/重试、任务状态和后台恢复。先用已有任务验证，不自动重放有费用的生成。
3. 核验剧本生成、小说获取、小说面板、Agent 工作区，保持真实权限与缺少能力时的提示。
4. 核验任务聚合与个人中心，确认账号切换后旧内容不回写、错误不会被成功状态掩盖。
5. 用真实手机检查首开、滚动、拖动探头、主题切换、网络中断与恢复、前后台切换；再准备体验版交付。
