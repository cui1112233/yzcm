# 小家伙自然行为与衔接

用户已确认：取消机械轮播，优先完成走动停稳、犯困趴睡与唤醒。保持现有造型和业务入口。

实施顺序：
1. 先测试独立状态控制器：普通活动低频选择；45 秒无触摸犯困；睡眠保持；唤醒先过渡再回应；隐藏暂停计时；拖动和点击优先；特殊动作完整播放后回到日常。
2. 原生组件使用同一控制器，补入短时停稳、低头困倦、落下与起身的视觉衔接。动作结束在完整循环边界退出，方向保持至停稳。
3. 独立浏览器示例使用相同行为逻辑，增加自动陪伴模式与暂停、明确动作状态。保留完整 SVG 研究稿为历史可编辑来源，不冒充新行为版本。
4. 更新源码包，执行状态机回归、TypeScript、微信构建，并在模拟器核对。

边界：衔接先用现有矢量造型补绘并导出有限帧率图集；真机性能与最终美术观感分别验证。减少动态效果时暂停自主行为；隐藏、卸载清理计时器。
