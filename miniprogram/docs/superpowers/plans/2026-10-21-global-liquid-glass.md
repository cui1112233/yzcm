# 公共液态玻璃实施

1. 公共主题根节点接入材质组件，排除插画登录页与主题切换预览副本。
2. 增加有界可见卡片采样、失效版本控制及离屏绘制；测试丢弃旧结果和滚动清除。
3. 全局样式统一卡片、输入、页内导航、弹窗和文字，替换功能页单卡实验接入。
4. 四个主入口使用公共悬浮玻璃导航，保持原 switchTab 路由；隐藏旧原生栏，失败时保留原生栏。
5. 运行全量测试、类型检查和构建，在微信开发者工具检查主题、页面、滚动、点击与登录页。

## 用户体验反馈后的调整

- 业务内页（剧本、小说获取、批量工厂等）恢复原有普通材质；保留四个主入口与个人资料页的玻璃界面，插画登录框保留。
- 降低透明度开关移到“我的”，沿用原偏好键并通知已缓存页面。
- 取消逐卡 Canvas 像素读取、临时图片导出与停滑后的折射覆盖层。改用常驻的 CSS 装饰和高光，滚动、触摸不再触发材质计算。
- 用户补充要求保留折射。使用同一折射算法离线生成九宫格边缘纹理，通过卡片伪元素随原生滚动一起移动，取消固定视口覆盖层；降低透明度时移除纹理。此方案是预计算光学材质，不是滚动背景实时折射。
