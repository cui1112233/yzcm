# 批量工厂提示词编辑设计

## 目标

在单本小说工作区中让用户编辑资产提示词和当前分镜视频提示词；保存必须由批量工厂 V12 服务端持久化，重新读取后仍显示服务端确认的内容。

## 范围与数据流

资产提示词编辑使用既有 `PATCH /api/batch-factory/v12/batches/{batchId}/books/{bookId}/assets/{assetId}`。请求带资产名称、提示词与 `expectedRevision`，服务端返回更新资产；客户端随后重新读取工作区，不能把草稿当作已保存结果。

视频提示词编辑使用既有 `PUT /api/batch-factory/v12/batches/{batchId}/books/{bookId}/videos/{videoId}/override`。请求体是 `{ patch: { videoPrompt }, expectedRevision }`。该覆盖是当前镜头的服务端生产配置，后续生成读取它，不修改其他镜头或整书配置。

## 交互

- 两个详情区均显示“编辑提示词”，进入编辑态后显示 `Textarea`、取消和保存。
- 空提示词不允许保存；保存期间禁用重复提交。
- 保存成功只提示服务端读回成功；冲突、权限或服务端拒绝保留草稿并展示错误。
- 保存完成调用既有工作区刷新，因此资产、阶段及任务提示词都以服务端结果恢复。

## 验收

1. 服务层测试验证两条 V12 写请求、路径编码、版本号、必填提示词和读回校验。
2. 组件测试验证资产和当前镜头分别可进入编辑态、保存与取消，并只调用自己的动作。
3. `npm test`、`npx tsc --noEmit` 与 `npm run build:weapp` 通过。
4. 微信开发者工具以新 `dist/` 验证编辑、保存、刷新后内容仍存在；生产重试前由真实服务端读取覆盖值。
