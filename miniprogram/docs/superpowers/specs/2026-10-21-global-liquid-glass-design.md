# 全小程序液态玻璃

用户确认：实际小程序全部页面，保留插画登录框。延续已认可的清透背景与折射边缘，不修改业务接口、数据、登录及生成链路。

统一卡片、按钮、页内导航、输入框、抽屉及四个一级入口。长文编辑区和弹窗采用更厚的玻璃底色保证可读性。浅色/深色同步切换；功能页的降低透明度对全部页面生效。

公共 ThemedPage 接入原生 Canvas 材质，复用一份壁纸和一个离屏绘制画布；只处理当前可见卡片，限制像素量和数量。滑动或按压立即隐藏过期折射层，停止后重算；返回/主题变化/窗口变化时刷新，退出后释放临时文件。失败时保留透明高光材质和完整交互，不阻断页面。

验收：四个一级页面、业务入口、浅深主题、降低透明度、滑动无重影、底部导航、登录插画不变。构建和模拟器可证明实现；真机帧率另行验收。不上传发布。
