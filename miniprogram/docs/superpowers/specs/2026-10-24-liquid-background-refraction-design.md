# 小程序公共页液态背景与常驻折射设计

## 目标

将微信小程序中的工作区、任务、功能、我的和个人资料页，统一为 `http://127.0.0.1:61977/` 中的冰蓝液态玻璃视觉。背景需保留参考页的冰蓝渐变、大弧形光带和柔和亮区；玻璃卡片中需始终看得到光学弯折，不得只有半透明底色或静态白边。

## 范围

### 使用液态材质

- 工作区 `pages/workspace/index`
- 任务 `pages/tasks/index`
- 功能 `pages/functions/index`
- 我的 `pages/profile/index`
- 个人资料及设置 `pages/profile-detail/index`
- 以上页面的公共底部导航

### 不使用液态材质

- 登录页继续使用已确认的蓝色插画登录框。
- 剧本生成、小说获取、水货生产、批量工厂等业务内页保持普通材质。
- 入场视频、角色动画和登录轮子不在本次改造范围内。

## 视觉设计

### 背景

- 浅色主题使用参考页的冰蓝背景：冷白高光、青蓝阴影、对角大弧形光带和下方水光区。
- 深色主题使用同一几何结构的深青版，不改变光带位置，保证主题切换时界面结构稳定。
- 背景以本地 PNG 资产提供，避免多层大面积 CSS 渐变在真机上重绘抖动。

### 玻璃表面

每个公共页卡片由四层组成：

1. 低透明的冰蓝填充，保持文字可读。
2. 常驻的局部背景折射纹理，包含放大、轻微偏移和弯曲的光带，在静止和滑动时都可见。
3. 玻璃边缘的亮边和内侧暗线，形成凸透镜厚度。
4. 内容层，文字和图标使用实色，不参与透明度混合。

折射是面向小程序的视觉模拟，不使用浏览器 SVG `backdrop-filter` 或持续的 Canvas 截图读回。验收标准是“折射清晰可见且全程稳定”，不是物理实时采样。

### 动态与交互

- 折射层始终存在，页面滑动时不隐藏，滑动结束时不突然显示。
- 按压仅使用 `transform` 和阴影变化，不触发背景重算。
- 低动效模式停止高光流动，但保留背景、透明度和静态折射。
- “降低透明度”继续位于服务／我的设置中；启用后提高填充不透明度，但保留边缘折射。

## 实现边界

- 替换 `LiquidGlassMaterial` 使用的浅色和深色背景资产。
- 将 `TextureRefraction` 从单层静态 rim 扩展为“折射纹理 + rim”两层结构，继续保持 `pointer-events: none`。
- 不改动各页的数据请求、导航、会话恢复、空状态或错误状态逻辑。
- 不扩大 `liquidEnabled` 的页面范围，只修复已在范围内页面的材质。
- 不复活滑动期间的 Canvas 截图、异步读回和逐帧 React/setData 更新。

## 验证

### 自动化

- 浅色和深色背景资产都被构建到 `dist/assets/glass/`。
- `TextureRefraction` 同时渲染折射纹理和边缘层，两层均不接收点击。
- 低透明模式不移除折射边缘。
- 业务内页和登录页不被全局液态样式覆盖。
- 全量测试、微信小程序生产构建和 WXSS 兼容检查通过。

### 视觉验收

在微信开发者工具和真机分别检查工作区、任务、功能、我的：

- 背景与参考页为同一冰蓝光带语言，不再显得脏或灰。
- 卡片静止时能看到背景光带的局部放大和弯曲。
- 连续滑动时折射不消失，停止时不闪现。
- 文字、按钮和导航保持清晰，点击、页面切换与滚动流畅。
- 登录页、入场动画和业务内页的外观与行为不变。
