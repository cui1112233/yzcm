# 私人定制漫画工作台布局设计

日期：2026-11-05  
范围：仅私人定制漫画；不改批量工厂页面、批量工厂任务链路或批量工厂入口。

## 1. 目标

将私人定制漫画从“正文、配置、生成、结果混在同一页”整理为可恢复的单本创作工作台。用户需要始终知道：当前阶段、下一步动作、哪些内容已经确认、哪些操作会触发真实生成、失败后可以重试什么。

目标链路：

`故事来源 → 资产提取 → 资产定妆 → 分镜确认 → 分页出图 → 成果导出`

本轮不追求增加能力，不新增模型、不新增后端业务规则，不把批次或多书选择暴露给私人定制用户。

## 2. 设计方向

采用“工作室 + 纸张 + 墨色”的移动视觉语言：深色画布承载创作空间，正文使用纸张质感卡片，人物/场景/道具使用缩略图作为视觉锚点，主操作使用柔和鼠尾草绿。保留小程序窄屏、触控、主题和安全区约束，不照搬桌面端三栏布局。

结构上采用“阶段工作台”，而不是把所有动作压缩为一个表单或只显示三个页面：

- 每个阶段有独立标题、说明和一个主动作。
- 阶段完成后锁定确认版本，同时允许返回修改。
- 生成阶段可离开并恢复，结果阶段支持逐页审阅和单页重做。
- 用户只在明确点击下一步或生成时触发写请求；输入和选择先留在本地草稿。

## 3. 页面与状态

### 3.1 私人定制入口 / 故事来源

首屏只保留单本创作所需内容：

- 故事来源切换：`粘贴正文`、`选择已有故事`。
- 唯一大文本输入为正文；显示字数、最小字数校验和“正文只用于本次私人定制”的说明。
- 画风为缩略图选择；画幅使用紧凑分段控件；参考图为可选上传入口。
- 主按钮为“继续：提取人物与场景”，未达到正文条件时禁用或给出就地原因。

本页不显示批次列表、多书选择、批量生成选项。

### 3.2 资产提取与定妆

将人物、场景、道具显示为可编辑资产卡片：

- 每张卡显示名称、类型、简短外形描述和当前主图。
- 资产图生成按资产集合提交，但结果按资产单独展示。
- “重新生成定妆图”只影响当前资产；资产失败不阻塞已成功资产。
- 主按钮为“继续：确认分镜”；次按钮返回故事来源并保留草稿。

### 3.3 分镜确认

以纵向分镜列表显示每页的页码、场景、人物、动作、镜头和提示词摘要：

- 默认折叠，仅展开当前页。
- 支持编辑单页描述、调整顺序、标记需要重做。
- 确认动作保存结构化分镜 revision/content digest，避免只保存一个不可追踪的大 prompt。
- 主按钮明确写“确认分镜，开始分页出图”，并提示确认后才会消耗生成资源。

### 3.4 分页出图 / 生成中

生成状态按真实阶段显示：

- 故事与资产：已锁定。
- 分页出图：第 N / 总数页、进度、当前页标题。
- 一致性检查：等待中 / 通过 / 失败。

每次运行使用稳定的 run/task 标识和幂等键；页面离开后重新进入按 `{batchId, bookId, runId}` 恢复，不自动重复提交。失败显示具体页或阶段，并提供“重试本页 / 重试失败阶段”，不以“生成中”掩盖终态错误。

### 3.5 结果与导出

结果页采用“大图 + 候选条 + 页码条”的移动布局：

- 主图为当前采用图，候选图横向滑动浏览。
- 页码条用于切换整本页面；切页时清理旧媒体加载状态，避免旧页晚响应挂回当前页。
- 高级操作只作用于当前页：换候选图、改提示词、重做本页。
- 导出分为“保存本页到相册”和“整本打包下载”，分别展示结果和失败原因。
- 原版本保留，重做生成创建新版本，不覆盖用户已采用的图。

## 4. 输入与数据边界

前端草稿字段：

```ts
type PrivateComicDraft = {
  sourceMode: "paste" | "existing";
  sourceText: string;
  existingStoryId?: string;
  styleId: string;
  aspectRatio: string;
  referenceMediaIds: string[];
};
```

只有以下动作触发真实请求：

1. 选择已有故事：读取已认证故事列表。
2. 继续提取资产：创建/确认本次私人作品，再调用资产阶段。
3. 生成资产图：提交选定资产 ID 和图像模型参数。
4. 确认分镜并出图：保存分镜 revision 后创建生产任务。
5. 结果读取：按真实 book/page/image 记录读取，不从任务列表猜测页面。
6. 保存/下载：保存本地相册或创建合集并读取下载回执。

现有服务边界优先复用：

- `comicFlow.ts`：正文 intake、私人作品创建、预设、生成启动和状态读取。
- `comicAssets.ts`：`stages/assets`、资产图生成、图片鉴权读取、阶段重试。
- `comicResult.ts`：`comic-pages`、合集、鉴权图片读取、保存和下载。

不在本轮新增第二套 comic API，也不把浏览器业务存储当作服务端持久化。

## 5. 高级交互

- **草稿恢复**：页面返回或重新进入时恢复输入和当前阶段；服务端已确认的版本优先于本地草稿。
- **乐观草稿 / 显式提交**：编辑正文、资产描述和分镜时只改本地草稿；点击阶段主按钮才提交。
- **局部重做**：资产、分镜页、结果页均支持局部重做；不得因为单页失败重跑整本。
- **版本与收据**：提交前记录 revision/content digest；未知结果保留 request/run receipt，禁止自动重复点击。
- **候选与采用分离**：候选图可浏览，只有用户明确选择后才成为 primary image。
- **主题与触控**：按钮最小触控区域不小于 44px；深浅主题同时校验卡片、输入框、辅助文字和图片占位的对比度。
- **离开页面**：轮询、图片加载和异步响应均绑定当前 run/page generation；离开或切换作品后取消旧任务，晚响应不得污染新页面。

## 6. 错误与不可用状态

所有阶段必须区分：

- 未开始：说明需要完成的前置条件。
- 进行中：显示真实阶段和当前对象。
- 成功：显示已完成数量、版本或回执。
- 失败：显示用户可理解的原因、具体作用域和可执行的重试动作。
- 未知：保留“结果待确认”，先读状态和历史，不自动重放。
- 无权限/登录失效：统一显示登录失效或权限不足，不泄露 401、appCode、provider exception 等技术原文。

## 7. 测试与验收

### 组件与交互测试

- 故事来源切换、正文长度校验、画风/画幅/参考图草稿保存。
- 每个阶段前进、返回和重新进入时状态保持。
- 资产卡片编辑、单资产重做、分镜单页修改和版本号更新。
- 生成轮询的 run/page 作用域、切换页面后的晚响应保护、失败重试不重复提交。
- 候选图与采用图切换、保存本页、整本下载错误处理。

### 微信开发者工具验收

- 320/375/390/430px 宽度，深浅主题，无横向溢出。
- 真实登录态下读取当前私人作品、资产、分镜、页面和鉴权媒体。
- 先用已有记录验证读取、候选、保存和下载；真实生成只在用户明确确认后执行。
- 不能用构建成功、HTTP 200、模拟 API 或页面打开代替真实任务回执、媒体读回和视觉验收。

## 8. 非目标

- 不改批量工厂的批次/多书生产链路。
- 不新增模型供应商、计费、队列或后端业务规则。
- 不把桌面端无限画布、复杂节点编辑器直接搬进小程序。
- 不在设计阶段执行真实付费生成、发布或上传。
