# 私人定制漫画公网对齐设计

日期：2026-11-05

## 背景与问题

小程序当前页面是独立拼出的“阶段工作台”，但公网的生产语义、资产能力和配置字段并不是同一套模型。公网明确区分图片画幅/视频画幅，资产页支持分类、搜索、手动维护、图片版本和主图；生产向导以真实前置条件驱动状态。小程序如果继续只增加阶段标题，会造成“看起来对应，点击后不对应”。

本次只对齐私人定制漫画的可用体验，不把批量工厂的批量选择、视频生产、发布和音频配置搬进小程序。

## 目标

1. 小程序的配置字段、标签和交互语义与公网统一。
2. 每个按钮只展示当前已有真实接口支持的动作。
3. 不支持的分镜编辑能力明确标记为只读/暂不可用，不伪造成功。
4. 保留小程序的移动端优势：单列、底部主操作、弹层和断点恢复。
5. 形成可测试的状态机，防止未确认配置直接启动正式生成。

## 非目标

- 不复制批量工厂的书单、并行生产、视频、配音、发布和剪辑导出。
- 不新增后端分镜编辑或资产绑定接口。
- 不改变现有漫画服务 endpoint、鉴权、媒体缓存和下载协议。
- 不自动重放未知或失败的付费生成任务。

## 对齐后的页面结构

### 1. 故事设置

字段按公网语义命名：

- 正文：必填，保留现有最小字数校验。
- 画风：来自公网同源 style catalog，显示名称和预览。
- 图片画幅：固定 `16:9 / 9:16 / 1:1`，传递为顶层 `imageAspectRatio`。
- 参考图：可选，上传后应用到资产和分页图片。

主操作为“创建项目并提取资产”，只创建批次、上传参考图并调用资产提取，不提交正式生成。

### 2. 资产工作台

移动端使用顶部分类筛选和资产卡片：人物、场景、道具。每张卡显示名称、外观描述、主图/未生成状态。

开放的真实动作：重新提取资产、补齐缺失资产图、重试失败阶段、刷新。当前 endpoint 不支持资产文本编辑、手动上传和主图切换时，显示只读说明，不提供假按钮。

### 3. 生成配置确认

当前后端没有独立分镜编辑/绑定接口，因此阶段名称使用“生成配置确认”，不再宣称可以编辑分镜。页面显示当前资产摘要、画幅、画风、参考图状态和生成前置检查。

主操作为“确认配置，开始分页出图”，仅在已有资产且前置检查通过后调用 `submitComicRun`。

### 4. 分页出图

正式任务提交后才进入该阶段。轮询读取真实 automation 状态，显示总进度、失败书目/错误、重试入口。阶段切换和页面卸载必须停止轮询。

### 5. 成果导出

读取 `comic-pages` 后开放：候选图预览、当前页保存到相册、整本合集下载。没有图片回执时禁用导出，不显示“已完成”的假状态。

## 公网对齐表

| 公网语义 | 小程序实现 | 当前限制 |
|---|---|---|
| 图片画幅 `16:9/9:16/1:1` | `imageAspectRatio` | 仅漫画图片，不显示视频画幅 |
| 资产分类/摘要 | 移动端分类卡片 | 暂无编辑/上传/主图 endpoint |
| 资产 AI 生图 | `assets/images/generate` | 支持缺图批量补齐 |
| 失败重试 | `stages/retry` | 只重试服务端最后失败阶段 |
| 分镜工作台 | 生成配置确认摘要 | 无独立分镜编辑接口 |
| 分页结果 | `comic-pages` | 以真实 page/image 回执为准 |
| 导出 | collection + download | 需要真实主图 |

## 状态与数据流

```text
source
  └─ createComicBatch → uploadComicReference? → extractComicAssets
      └─ assets
          └─ asset checks pass → config
              └─ submitComicRun
                  └─ render polling
                      └─ comic-pages → result/export
```

任何阶段切换都不能隐式触发下一个阶段的有费调用。只有显式点击“确认配置，开始分页出图”才允许提交正式任务。

## 错误与恢复

- 创建项目失败：保留正文草稿，允许再次创建；不自动重放正式任务。
- 资产提取失败：留在资产工作台，显示重试和重新提取。
- 资产图片单项失败：卡片显示未生成，不阻塞其他资产。
- 正式生成失败：显示服务端阶段错误，提供手动重试，不自动重发。
- 媒体读取失败：保留页面状态，单张显示不可用，不清空其他页面。
- 登录失效：统一显示中文登录失效提示。

## 视觉设计原则

- 视觉语言参考公网的“配置卡 + 状态标签 + 明确动作”，但适配小程序单列布局。
- 阶段头部只展示真实阶段，不使用可点击但无法进入的假入口。
- 每个阶段只有一个主动作；次要动作放入卡片内。
- 画幅、状态、模型等技术字段使用公网原词，不再使用容易产生歧义的“横版/竖版”替代比例。
- 深浅主题、320/375/390/430px 宽度下都不得横向溢出。

## 验收标准

1. 创建项目后 `submitComicRun` 尚未调用。
2. 资产阶段能看到真实资产读取和补图状态。
3. 没有资产时不能确认配置并开始生成。
4. 确认配置后才开始轮询正式任务。
5. 画幅选项与公网完全一致，提交字段为 `imageAspectRatio`。
6. 结果导出按钮只在真实主图存在时可用。
7. 漫画测试、构建和状态机测试通过；全仓既有 TypeScript 错误单独记录。
