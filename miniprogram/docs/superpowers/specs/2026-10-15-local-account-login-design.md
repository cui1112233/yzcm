# 本地账号登录

用户已选择：先用本地账号密码登录，跑通业务。

开发构建连接已运行的 `http://127.0.0.1:13192`。仅回环地址启用本地账号登录入口，调用现有 `POST /api/login`，由后端验证密码并返回真实令牌。正式 HTTPS 构建继续使用微信授权及绑定；不改正式环境配置。

复用绑定页的输入框并按环境显示“本地登录”，启动无令牌时转入该页，401 时返回登录页且不自动重发业务写请求。本地令牌和绑定凭证以源站隔离；不保存密码，不复制公网令牌。资料加载与批量工厂保留真实加载、失败和空状态，原有批量写限制不改变。

当前本地服务未配置视频生成/发布，不承诺这些能力可用。开发者工具需要允许本地 HTTP 调试；仅调整开发专用配置。

验证：回环识别、密码请求范围、环境令牌隔离、401 不调用微信、不重放操作、错误密码失败、已有本地账号的受保护读取（如有可用的安全登录输入）；全部测试、类型检查、Taro 构建及开发者工具编译。没有用户密码时不猜测账号，真实登录验收由用户输入完成。
