# 一战晟铭小程序 1.1.0 液态玻璃设计

## 目标

在真实 `1.0.11` 公共页面结构和壁纸基础上，发布独立的 `1.1.0` 视觉版本。新版本采用“丝滑优先”的液态玻璃：中心清透，折射集中在弧形边缘，滚动期间持续可见但不过度运算，不再出现停止滑动后折射突然跳出的现象。

登录入场动画、循环车轮、账号登录、批量工厂、媒体播放、资料页防卡死和现有业务接口保持不变。

## 版本身份与防回滚

- `1.0.11` 是只读体验版视觉基线，不再用新构建覆盖其身份。
- 新液态玻璃版本固定为 `1.1.0`。
- `src/config/release.ts` 同时导出语义版本、短构建号和材质代号；登录页显示 `v1.1.0 · <短构建号>`。
- 构建号来源于当前 Git 提交短 SHA；无法读取 Git 时构建必须失败，不允许退回固定假值。
- 生产构建生成版本清单，至少记录版本、完整提交 SHA、构建时间、壁纸哈希和材质代号。
- 上传前校验源码版本、`dist` 版本和版本清单一致；校验失败时禁止上传。
- 实现提交后创建不可变 Git 标签 `miniprogram-v1.1.0`。上传和替换体验版仍需单独确认，不属于本次本地实现自动步骤。

## 页面范围

液态玻璃仅用于以下公共页面：

- 工作区
- 任务
- 功能
- 我的
- 个人资料公共页

剧本生成、小说获取、小说面板、水货生产、批量工厂和其他业务内页继续使用普通材质，避免复杂表单、视频与长列表产生额外合成负担。

“降低透明度”保留在“我的 > 服务”。开启后停止动态折射，使用更稳定的不透明表面和更高文字对比度。

## 视觉材质

### 背景

- 沿用从真实 `1.0.11` 缓存恢复的浅色、深色 PNG 壁纸及 `scaleToFill` 几何关系。
- 不再使用另一张近似 Web 背景作为 Canvas 采样源。
- 工作区原有头图完整保留，头图不得被壁纸、折射层或主题过渡层隐藏。

### 玻璃表面

- 中心保持清透，只使用低透明度色膜维持文字可读性。
- 主要折射位于圆角边缘的窄带区域；边缘包含轻微位移、聚光和暗沿。
- 主卡片折射稍强，次卡片更克制；列表行不重复叠加多层边框。
- 阴影保持短而轻，不使用大面积灰雾、白色蒙版或脏色覆盖。
- 按压使用小幅缩放和弹性恢复，不改变卡片稳定尺寸，不影响点击区域。

## 丝滑实现

- 使用一个页面级折射调度器，不为每张卡片创建独立动画循环。
- 滚动过程中通过 `requestAnimationFrame` 合并更新，持续显示最新有效折射帧。
- 新帧未就绪时保留旧帧，不隐藏折射层，因此不会在滑动暂停时突然出现。
- 每帧只处理视口内最多 4 个主要玻璃表面；超出部分使用同参数的静态边缘材质。
- Canvas backing scale 上限为 `1.25`，优先保证中低端设备滚动和点击响应。
- 页面隐藏、主题切换、组件卸载时取消旧任务，禁止迟到帧覆盖新主题。
- Canvas 或图片采样不可用时立即降级为静态玻璃，页面仍可点击、可滚动、文字可读。

## 主题切换

- 保留工作区右上角的浅色／深色切换入口。
- 切换动画使用圆形揭示，但背景、头图、文字和玻璃材质必须在同一主题快照中更新。
- 新主题首帧准备完成前保留旧主题，禁止白闪、空帧和头图消失。
- 深浅主题分别使用独立边缘亮度和文字颜色，不用同一套白色高光硬套两种背景。

## 组件边界

- `ThemedPage`：决定页面是否进入公共液态材质范围，并挂载唯一页面级材质层。
- `LiquidGlassMaterial`：显示壁纸、静态边缘和降级材质，不拥有业务页面状态。
- `DynamicGlassCanvas`：只负责可见表面的折射采样和帧复用，不绘制正文或接管点击。
- 折射调度器：收集可见表面矩形、合并滚动更新并丢弃过期帧。
- 公共页面通过统一的主卡／次卡角色声明材质，不再维护页面专属的重复玻璃伪元素。

## 验收标准

1. 登录页显示 `v1.1.0 · <短构建号>`，版本清单的 SHA 与当前实现提交一致。
2. 工作区、任务、功能、我的和个人资料在浅色、深色主题下均有清透中心和可辨识的弧边折射。
3. 连续滚动期间折射不消失，停止滚动时不跳变；按钮和 Tab 切换无明显迟钝。
4. 工作区头图完整显示，主题双向切换无白闪、空帧或遮挡正文。
5. “降低透明度”位于“我的 > 服务”，开启后文字对比度提高且动态折射停止。
6. 所有业务内页保持普通材质，功能、输入、视频和长列表不受公共材质影响。
7. 登录动画和循环车轮相关源码、素材哈希与 `1.0.11` 恢复前保持一致。
8. 全量测试、TypeScript、生产构建、版本一致性校验和 `git diff --check` 通过。
9. 微信开发者工具逐页视觉检查通过后，才进入上传或替换体验版步骤。

## 非目标

- 不追求桌面 Safari 的逐像素实时光学模拟。
- 不在业务内页启用动态液态玻璃。
- 不修改登录动画、业务接口、账号数据、路由或服务端。
- 不在本地验收前自动上传、发布或覆盖体验版。
