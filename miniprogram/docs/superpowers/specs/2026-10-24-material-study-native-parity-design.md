# 小程序 Material Study 原生材质对齐设计

## 目标

把 `previews/liquid-glass/material-study.html` 的青蓝曲线背景、光晕、清透中心、弧面折射、边缘聚光和按压回弹完整迁移到微信小程序公共页面，同时保留工作区头图与现有业务页面普通材质边界。

## 页面范围

- 工作区、任务、功能、我的及个人资料公共页使用 Material Study 液态玻璃。
- 工作区的 `home-art-glass.png` / `home-art-glass-dark.png` 头图继续完整显示，不得以显示壁纸为理由隐藏。
- 剧本生成、小说获取、小说面板、水货生产、批量工厂等业务内页保持普通材质。
- “降低透明度”仍位于“我的 > 服务”，开启后使用稳定不透明底色并停用折射采样。

## 材质架构

### 同源背景

用参考页 `material-study.js` 的固定参数生成 780 x 1500 浅色与深色背景资源：

- 浅色渐变：`#e5f3ed`、`#c0e5e4`、`#6eafc3`。
- 深色渐变：`#173a4b`、`#29576a`、`#132c48`。
- 四组椭圆曲线分别使用参考页的颜色、位置、旋转、半径与线宽。
- 左上径向光晕使用参考页的中心、半径和透明度。

`LiquidGlassMaterial` 显示该资源；`DynamicGlassCanvas` 从同一资源取像素。显示与采样使用同一个 `aspectFillSourceRect` 裁切结果，禁止另画一套近似背景。

### 折射与卡片

- 主卡片以参考页 2 倍 Canvas 为基准换算到 CSS 尺度：圆角 30px、折射带 13px、最大弯折 12.5px。
- 次卡片保持较轻折射：圆角 24px、折射带 8px、最大弯折 6px。
- 中心保持清透，折射集中在弧形边缘；高光、内沿和阴影恢复到参考页强度。
- 按压保持 `scale(.97,.92)` 的纵向压缩感，并使用弹性回弹曲线。

### 主题切换

- 保留从工作区右上按钮发起的圆形展开／收回。
- 切换克隆层必须包含目标主题的同源背景材质，先渲染首帧，再开始裁切过渡。
- 工作区头图、文字、状态卡和背景在过渡层中的位置必须与当前滚动状态一致。
- 折射 Canvas 切换主题时保留旧帧，直到新背景像素加载并完成首帧绘制，避免过渡结束时闪空。

## 性能与失败策略

- 折射 Canvas backing scale 上限保持 1.5 倍。
- 单帧最多处理 6 个可见折射表面。
- 背景资源加载或 Offscreen Canvas 不可用时，保留同源背景和 CSS 高光，隐藏动态折射层；不得显示空白或阻塞点击。
- 不新增滚动期间持续动画循环；滚动合并到现有 `requestAnimationFrame` 调度。

## 验收

1. 自动化测试证明头图不可被液态样式隐藏，浅深背景均来自同源资源，折射参数与参考页换算一致。
2. `npm test -- --run` 全量通过，`npm run build:weapp` 成功。
3. 微信开发者工具中验证工作区、任务、功能、我的：背景构图一致、文字清晰、卡片边缘可见折射、滚动不中断点击。
4. 工作区浅到深、深到浅双向切换均有连续圆形过渡，无白闪、空帧或头图消失。
5. 业务内页不获得液态背景或动态折射。

## 非目标

- 不改登录页插画与登录动画。
- 不改业务接口、账号状态、页面路由和原生 TabBar 信息架构。
- 不上传、不发布新版本。
