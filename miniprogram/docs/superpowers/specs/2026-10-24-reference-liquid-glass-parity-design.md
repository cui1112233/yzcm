# 小程序参考液态玻璃视觉对齐设计

## 目标

以 `http://127.0.0.1:61977/material-study.html` 中“现在 / 清透中心 · 弧面折射”的剧本生成卡片为唯一视觉基准，重做小程序公共外层页面的玻璃材质。目标不是增加白色描边，而是让背景从卡片中心透过，并在圆角厚边缘中发生可见、连续的弯折。

适用页面：工作区、任务、功能、我的及个人资料外层页面。

不适用范围：剧本生成、小说获取、批量工厂、水货生产等业务工作台内页；这些页面继续使用普通高可读材质。

## 视觉基准

玻璃卡片必须同时具备以下特征：

1. 中心清透：卡片中央能看见同坐标的页面背景，不使用大面积乳白或灰蓝色蒙层遮住背景。
2. 弧面折射：约 20-26px 的圆角边缘带对背景进行连续位移采样；折射不能退化成几条直线、色块或 1px 白框。
3. 材质厚度：顶部和左侧有柔亮内高光，底部和右侧有蓝灰内阴影，外部只有克制的软阴影。
4. 局部承托：标题与说明文字背后允许使用小范围、渐隐的阅读光晕，但不得把整张卡片填成不透明底色。
5. 圆角与比例：主要入口卡片使用接近参考页的 28-30px 圆角和横向扁平比例，不统一拉成同一种高度。
6. 按压反馈：按下时轻微压缩并收紧阴影，松开后平滑回弹；不改变布局尺寸。

## 页面层级

### 背景

- 使用用户于 2026-10-24 确认的竖版蓝色流体壁纸原图作为唯一构图来源，不再用渐变、椭圆或光带脚本近似重绘。
- 浅色主题保留原图色彩；深色主题只允许在同一像素构图上做整体压暗和轻微降亮，不移动、重画或新增光缝。
- 图片按视口 `cover`、水平居中、垂直居中裁切；禁止非等比拉伸。页面可见背景与离屏折射源必须使用同一主题资产、同一裁切矩阵和同一坐标。
- 原图左侧及上半部的安静蓝色区域用于承托标题、导航和主要文字；右侧暖色光缝作为折射参照，不再叠加旧版大弧带。
- 资源生成脚本不得覆盖这两张经确认的壁纸；若需要调整尺寸，只能从确认原图等比裁切和缩放。

### 玻璃角色

- 主要入口卡片：使用完整实时折射、内高光、内阴影和按压反馈。
- 次级信息卡片：沿用相同清透材质语言，但降低折射强度，不出现重复的亮白轮廓。
- 密集列表：只在容器层使用玻璃，列表行本身用分隔线和留白组织，避免每一行都变成独立白框。
- 错误、状态与标签：使用稳定的语义底色保证可读性，不参与折射。

## 技术结构

### 背景层

普通图片或普通 WXML 层负责展示背景，保持在交互内容之后。背景资源和运行时折射采样源必须来自同一绘制算法或同一位图。

### 光学层

保留透明的全屏 Canvas 作为小程序兼容方案，但只绘制已标记的玻璃区域，不重绘整张背景，也不覆盖正文。每帧只处理当前视口内必要的卡片：

- 使用圆角有符号距离计算边缘带，而不是四边逐行复制。
- 边缘位移曲线与参考页一致，中心保持同坐标采样。
- Canvas 只输出折射像素与必要的边缘高光，不输出通用白色描边。
- 滚动位置通过单一帧调度器更新，布局测量只在页面显示、尺寸变化或内容结构变化时执行。

### 材质层

WXML/WXSS 负责内高光、内阴影、外阴影、文字光晕和按压状态。材质样式通过明确角色类绑定，禁止再用一个全局选择器覆盖所有 `.mp-card`、`.tools-entry` 和业务面板。

## 页面调整

- 工作区：修复头图、时间卡和问候信息重叠；时间卡退出负边距与粘性定位冲突；快捷入口按参考材质显示。
- 任务：活动摘要使用主要玻璃；任务列表使用一个清透列表容器，单行不重复画完整玻璃边。
- 功能：入口卡片直接对齐参考图；剧本生成卡片作为首个精确验收样本，其余入口复用同一材质结构。
- 我的：账号信息与用量卡使用玻璃；设置列表按分组容器组织，避免每行白框；“降低透明度”继续位于服务分组。
- 个人资料：仅外层摘要卡使用玻璃，表单和长文本区域使用稳定阅读底色。

## 性能与降级

- 默认最多绘制当前视口内 6 个玻璃区域，优先主要入口与大容器。
- 折射绘制跟随 `requestAnimationFrame`，同一帧合并滚动更新。
- 降低透明度开启时停用实时折射，改为高对比度实色面板。
- Canvas 或离屏 Canvas 不可用时退化为清透渐变与内阴影，功能和文字仍可用。
- 真机性能验收关注滚动帧稳定、页面切换、长任务列表及“我的”页面。

## 验收标准

1. 功能页“剧本生成”卡片与参考页截图在清透中心、弧面折射、边缘厚度、圆角和内外阴影上达到同一视觉语言。
2. 背景弧线在卡片边缘发生连续弯折，卡片中心显示未位移的同坐标背景。
3. 工作区标题、时间、问候、角色和快捷入口没有重叠。
4. 任务和“我的”页面不再出现逐卡重复的 1px 白框，也不被大弧线切碎。
5. 所有主要文字在深浅主题及降低透明度模式下均清晰可读。
6. 开发者工具逐页截图完成对照；构建、测试或 Canvas 出现本身不能替代视觉验收。
7. 真机验证滚动与切页流畅性，在完成真机验证前不宣称最终发布质量通过。
8. 浅色页面与用户确认原图保持同一构图；深色页面仅降低亮度。页面底图与玻璃折射中的光缝位置连续一致，不出现两套背景或裁切错位。
