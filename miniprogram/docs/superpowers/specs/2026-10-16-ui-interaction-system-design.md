# 移动生产工作台 UI 与交互统一规范 v1.0

日期：2026-10-16。状态：用户已确认并要求执行；基础系统与批量工厂四页已本地实施，原生与真实业务验收边界见 `../../2026-10-16-ui-system-implementation-status.md`。

## 1. 目标与范围

为当前微信小程序建立可执行的排版、留白、配色、组件布局、动效交互规范。视觉方向为：中性色生产工作台、暖色主要操作、列表优先、真实媒体突出。参考移动剪辑工具对内容和工具的层级组织，不复制其品牌外观。

统一基础规则，但不强迫所有页面使用同一种布局。独特性来自真实内容、业务结构和克制的品牌表达，不能由令牌或量化检查单独保证。

仅处理本地设计规范及后续本地客户端适配。不修改公网代码、配置、数据库、账号密码；不部署、不提交、不推送。保留现有未提交修改。既有服务层、会话、权限和业务能力不因视觉改造重写；不得自动运行付费生成、上传、发布或定时任务。

当前实现依据：同目录 `2026-10-16-batch-mobile-interaction-design.md`。该文档中的业务链路与操作边界继续生效；本规范负责视觉和交互基础，发生冲突时先记录差异，不静默删减已有功能。

## 2. 规则等级与单位

- MUST：可读性、触控、状态含义、操作范围、安全区、数据隔离必须符合。
- DEFAULT：字号、间距、颜色、圆角、布局和时长直接使用默认值。
- EXCEPTION：封面、播放器、时间轴等可采用专用规则；记录组件、原因、影响和验收依据。

所有尺寸为视觉逻辑 px，不是物理像素。项目使用 Taro，必须根据实际配置统一转换；不可把本文件数值原样当作 rpx。375 逻辑宽度下用真机测量校验转换，误差不超过 1 逻辑 px。系统字体放大后不按此误差约束文字。

## 3. 排版

使用系统中文字体；不新增正文装饰字体依赖。字体令牌如下。

| 令牌／用途 | 字号／行高 px | 字重 | 正例 | 反例 |
|---|---|---|---|---|
| type.page／页面主标题 | 24／32 | 600 | 每页一个“批量工厂”主标题 | 多个区块都使用超大粗体 |
| type.section／区块标题 | 18／26 | 600 | 小说列表、合成与提交 | 标题正文只靠颜色区分 |
| type.item／作品小说名称 | 16／24 | 600 | 最多两行，进入后可见全名 | 缩成 11px 来容纳长书名 |
| type.body／正文提示词 | 16／26 | 400 | 左对齐连续阅读 | 大段居中、全段粗体 |
| type.control／标签按钮页签 | 14／20 | 500 | 同类按钮字重一致 | 每个按钮不同字号 |
| type.caption／辅助说明 | 12／18 | 400 | 时间、来源等次要信息 | 用辅助字号呈现关键限制 |

| 规则 | 数量标准 | 正例 | 反例 |
|---|---|---|---|
| 字号层级 | 单屏常规区域最多 4 档字号、3 档字重 | 标题正文辅助三级清楚 | 每行一个字号 |
| 中文字距 | 默认 0，不使用负字距 | 自然排列 | 拉开中文正文制造高级感 |
| 英文短标签字距 | 0～0.04em | 少量品牌标签 | 全页字距特效 |
| 对齐 | 标题正文表单左对齐；数值列右对齐 | 数量容易比较 | 列表正文居中 |
| 数字 | 时间数量进度使用等宽数字；不可用时保持固定容器宽度 | 更新不抖动 | 数字变化挤动相邻控件 |
| 长文本 | 折叠默认 4 行，提供展开与复制；完整内容不裁掉 | 原文可连续阅读 | 省略后没有查看入口 |
| 阅读字号 | 16／18／20 三档，行高约 1.65 | 只改变阅读区 | 阅读设置改变所有按钮大小 |

## 4. 留白

space 基准为 4px；允许序列 2、4、8、12、16、24、32、48。2px 仅用于光学和边框补偿。

| 场景 | 默认标准 | 正例 | 反例 |
|---|---|---|---|
| 图标与文字 | 8px | 按钮内容形成整体 | 各按钮间距不同 |
| 标签与输入框 | 8px | 标签清楚归属字段 | 标签更靠近上一字段 |
| 同组字段 | 16px | 来源与书籍 ID 归组 | 每个字段独立大卡片 |
| 区块内部 | 12～16px | 标题说明内容关联紧密 | 一行说明上下各 32px |
| 独立区块 | 24～32px，至少为组内间距的 1.5 倍 | 导入配置启动分段清楚 | 所有间距统一 8px |
| 手机页面边距 | 宽度≤359px：16px；360～599px：20px | 标题列表表单共用边线 | 每个区块独立左右边距 |
| 列表行 | 上下各 16px，左右服从页面 | 长内容自然增高 | 固定高度截掉第二行 |
| 底部操作栏 | 上下各 12px，另加系统安全区 | 按钮避开系统手势区 | 只适配一种手机 |
| 正文底部保留 | 实际操作栏总高度＋16px；总高度含安全区 | 最后一项可完整滚出 | 写死大空白或重复加安全区 |

键盘出现时，当前输入框、错误说明及下一步可通过滚动访问。不能用空白把主操作推到屏幕外。

## 5. 色彩

语义令牌由一个全局来源维护；页面不得各自发明主色。下表为默认纯色。

| 语义令牌 | 浅色 | 深色 |
|---|---|---|
| color.canvas | #F5F6F7 | #101214 |
| color.surface | #FFFFFF | #1B1E22 |
| color.text | #1B2025 | #F4F3EF |
| color.textMuted | #65707B | #A4A9B0 |
| color.divider | #DCE0E4 | #34383E |
| color.accent | #B84028 | #FF896C |
| color.onAccent | #FFFFFF | #27160F |
| color.controlBorder | #7B858F | #7E8792 |
| color.disabledSurface | #E8EBEE | #2B3036 |
| color.disabledText | #59636E | #A4A9B0 |

已计算纯色对比：浅色主按钮 5.52:1；深色主按钮 7.49:1；浅色次要文字对白底 5.05:1；深色次要文字对深表面 7.07:1。透明度、图片和叠层后的结果需重新计算，不沿用这些数值。

普通文字≥4.5:1；大文字≥3:1；必要控件边界、选中标记≥3:1。大文字按 WCAG 定义判断，普通 18px 标题不自动属于大文字。divider 仅用于装饰分隔；依赖边线识别的输入框使用 controlBorder。

| 状态令牌 | 浅色／深色 | 正例 | 反例 |
|---|---|---|---|
| success | #167347／#6DD6A3 | 图标＋已完成 | 仅绿点 |
| warning | #8A5700／#F2C66D | 原因与下一步 | 所有处理中都是黄色 |
| error | #B42318／#FF9A91 | 失败原因与处理入口 | 只显示错误二字 |
| info | #175CD3／#9AC2FF | 明确说明 | 蓝色同时代表一切状态 |
| disabled | disabledSurface＋disabledText | 禁用且有原因 | 整区降低透明度到看不清 |

状态色用于文字、图标，组合实际表面后逐项测量。状态不能只靠颜色区分。未知、未开始、处理中、失败、不可用分别建模。

深浅模式独立映射语义，不整体反色；Logo 使用适配资源，图片和视频保持原色。正例：深色背景使用可识别 Logo；反例：整体 brightness 滤镜破坏品牌颜色。

## 6. 栅格、组件与组合

| 屏幕宽度 px | 列数／沟槽 | 默认组织 | 反例 |
|---|---|---|---|
| ＜600 | 4／12px | 单列任务流，资产图可两列 | 正文输入强行两列 |
| 600～1023 | 8／16px | 列表详情分区，页面边距 24px | 按手机界面无限拉宽 |
| ≥1024 | 12／24px | 导航内容属性分区，页面边距 32px | 每块各自居中 |

桌面常规内容最大宽度 1280px；连续阅读最大宽度 720px。原生导航和系统安全区优先，不叠加伪微信导航。

| 组件 | 尺寸与行为 | 正例 | 反例 |
|---|---|---|---|
| 主按钮 | 高 48px，圆角 8px，水平内边距 16px | 当前区一个主要动作 | 多个同权重彩色按钮 |
| 次按钮 | 高 44～48px，中性背景或边框 | 取消、查看配置 | 与执行争夺注意力 |
| 图标按钮 | 图形 20／24px；触控≥44×44px，优先 48×48px | 易点且有无障碍名称 | 只能点中图标笔画 |
| 输入框 | 高 48px，字 16px，水平内边距 12px | 标签可见，错误在字段下方 | placeholder 代替标签 |
| 页签 | 高≥44px，字 14px，多项允许横滚 | 文字＋位置标记表示选中 | 只改变浅色文字 |
| 底部面板 | 顶圆角 16px；最高为可用高度 85%，其余内部滚动 | 关闭入口、固定操作区、焦点恢复 | 按钮被长内容挤掉 |
| 图片 | 圆角 8px；资产详情保留原比例，可全屏预览 | 看完整人物设定 | 裁掉头部或图片文字 |
| 视频 | 保留源比例，控制栏可用；缺失时紧凑状态区 | 真实播放与失败反馈 | 永久黑色占位 |
| 列表 | 自适应高度，标题≤2行、元信息≤2行；详情完整展示 | 一行代表一个作品 | 一个作品拆成多张功能卡 |
| 图标 | 同一线性图标族；24px基准约1.75～2px线宽 | 光学粗细统一 | emoji、实心、细线混用 |

组合 MUST：容器嵌套≤2层；同一操作区最多1个高强调按钮；相邻独立触控目标默认间距≥8px。普通表面默认无阴影，悬浮工具栏和覆盖层才使用阴影。加载保持布局结构，不反复移动播放器、按钮和正文。

层级采用语义：content、sticky、dock、scrim、modal、toast；modal 高于自身遮罩，toast 不遮住确认按钮；平台原生视频和覆盖层能力须真机验证，不认为增大 z-index 必然有效。

## 7. 业务页面模式

| 页面 | 强制结构 | 正例 | 反例 |
|---|---|---|---|
| 批量工厂首页 | 个人作品列表、搜索筛选、新建批量 | 首页一个清楚入口 | 首页先铺全部小说分镜 |
| 新建批量 | 导入来源与 ID→统一配置→启动方式→提交摘要 | 可添加书城；仅导入、立即执行、定时互斥 | 缺配置、永久展示定时字段 |
| 作品详情 | 小说列表、选书、统一配置、批量执行、运行状态 | 返回恢复列表位置 | 进入后失去新建与配置路径 |
| 单书工作区 | 当前书；分镜／资产／原文／任务；合成与提交独立入口 | 各内容可切回 | 更新一处丢掉另一处入口 |
| 分镜详情 | 当前分镜视频、提示词、状态同步切换 | 每项属于同一镜 | 视频换了提示词没换 |

组件共享不等于页面同构。其他工作区、任务、功能、个人中心后续沿用基础规则，保留各自业务结构；不得借统一视觉删减公网现有功能。

## 8. 动效

| 类型 | 时长／曲线 | 正例 | 反例 |
|---|---|---|---|
| 按压反馈 | 80～120ms／ease-out | 颜色反馈，大按钮最多缩至0.98 | 整个表单弹跳 |
| 页签状态 | 120～180ms／cubic-bezier(.2,0,0,1) | 短距离移动 | 重播整页入场 |
| 折叠展开 | 180～240ms／同上 | 说明内容归属 | 动画阻止继续操作 |
| 面板进入 | 240～300ms／cubic-bezier(.16,1,.3,1) | 清楚表达覆盖关系 | 无意义多次回弹 |
| 面板退出 | 160～220ms／cubic-bezier(.4,0,1,1) | 快速返回 | 关闭等待一秒 |
| 页面过渡 | 180～240ms／ease-out | 优先原生导航 | 原生与自定义动画叠加 |

| 高级交互 | 条件与范围 | 正例 | 反例 |
|---|---|---|---|
| 滚动视差 | 仅非关键封面，位移≤±12px；离屏停止 | 轻微景深 | 提示词输入和视频漂移 |
| 时间轴跟随 | 播放头保持视口30%～70%；手动拖动立即暂停跟随 | 用户点回到播放位置恢复 | 用户拖走又被强拉回来 |
| 步骤跟随 | 吸顶只一层；定位标题距离固定栏≥16px | 明确当前步骤 | 多层吸顶吃掉正文 |
| 拖动跟随 | 专用手柄；释放吸附120～180ms | 拖动与滚动清楚区分 | 轻触整行触发排序 |
| 指针跟随 | 仅桌面精确指针；位移≤6px；不承载必要信息 | 可选封面微动 | 手机模拟光标、按钮躲手指 |

这些是能力适用标准，不是要求新增时间轴、排序或视差功能。现有业务不需要的动效不开发。

优先 transform／opacity；避免滚动中逐帧读写布局。目标设备60fps、每帧约16.7ms；达不到时首先移除装饰动画。单视口最多1类装饰循环，视频播放页默认0类。

支持平台减少动态效果设置；平台无法读取时提供减少动效开关。开启后关闭装饰位移与视差；必要反馈采用即时状态或≤100ms淡入。自动播放头仍表达真实播放位置，但不自动滚动时间轴。禁止用动画模拟业务进度。

## 9. 状态和交互契约

| 场景 | MUST | 正例 | 反例 |
|---|---|---|---|
| 首次读取 | 普通资料读取默认15秒超时，可手动重试；长任务接口单独定义 | 局部加载与失败原因 | 无限读取账号资料 |
| 空数据 | 解释范围与下一步 | 本书暂无视频，前往生成 | 用假视频填充 |
| 权限不足 | 保留上下文并解释权限 | 当前账号无提交权限 | 空白页面 |
| 提交中 | 即时反馈、禁止重复提交 | 正在提交 | 多次创建同任务 |
| 异步任务 | 已提交／处理中／成功／失败分离 | 回执只表示已提交 | HTTP成功称生成完成 |
| 重试 | 读取可重试；收费生成上传提交不自动重放 | 用户确认后重新发起 | 自动重复扣费 |
| 返回 | 保留筛选、选书、滚动和未提交输入；敏感字段不持久化 | 回到原小说行 | 回首页丢上下文 |
| 切换账号或书籍 | 旧响应不得更新新页面；确认绑定原账号和对象 | 新书只显示新书内容 | 串书串账号 |
| 播放 | 区分缺失、加载、失败、失效；允许重新读取链接 | 可处理的播放失败 | 永久黑屏 |
| 操作范围 | 动词＋对象＋必要范围 | 生成整书视频 | 只有执行二字 |
| 弹窗与键盘 | H5锁定焦点、Escape关闭非强制弹窗、关闭后恢复焦点；微信保持明确关闭与返回 | 可完成整条操作 | 焦点落到遮罩后方 |

取消确认不产生请求；生成、合成、提交沿用既有确认和操作锁；刷新状态只读取、不重放任务。

## 10. 审美和例外管理

| 维度 | 默认边界 | 正例 | 反例 |
|---|---|---|---|
| 焦点 | 每视图1个明确内容主体 | 视频或当前原文突出 | 装饰头图压过内容 |
| 强调 | 每操作区1个高强调焦点 | 执行按钮突出 | 每入口不同颜色 |
| 装饰 | 生产区默认无装饰渐变、玻璃、发光框 | 真实封面建立识别 | 全站科技背景 |
| 圆角 | 常规8px、浮层16px；胶囊仅小标签等 | 类型明确 | 万物巨大圆角 |
| 文案 | 动作＋对象 | 合成当前书视频 | 开启创作之旅 |
| 密度 | 通过折叠次要信息减少密度，关键正文≥14px | 正文默认16px | 全页11px塞信息 |

允许例外须写明：组件／场景、偏离令牌、业务理由、无障碍和性能影响、截图证据。不得以“更高级”“更有AI感”作为理由。像素合规之外仍需人工审阅内容焦点、节奏和品牌辨识度，不承诺审美可以完全自动化。

## 11. 落地与验收

交付结构：全局语义令牌单一来源；通用组件状态契约；业务页面模式；正反例和截图验收集。后续计划先映射 `src/app.scss`、`src/theme.tsx`、`src/components`、`src/pages/batch/mobile.scss`，避免再向已有样式尾部反复叠加覆盖。

实施顺序：基础令牌与主题→批量工厂首页→新建批量→作品小说列表→单书工作区→其他模块。每步保留已有功能入口，基础检查通过后再推进下一步。

| 验收项 | 通过标准 |
|---|---|
| 手机布局 | 320／375／390／430px无意外横向溢出；显式时间轴等除外 |
| 文字放大 | 最大系统字号；H5额外检查200%文本放大，关键内容和操作可访问 |
| 主题 | 深浅逐页覆盖Logo、文字、输入、选中、错误和禁用 |
| 触控 | ≥44×44px，优先48px；独立目标默认间隔≥8px |
| 对比度 | 测量实际前景背景组合；普通文字4.5:1，必要非文本3:1 |
| 长内容 | 两行书名、长ID、多段提示词、多书列表均可完整访问 |
| 状态 | 加载、空、失败、无权限、运行、成功分别验证 |
| 动效 | 减少动效可完成业务；手动滚动不被自动跟随抢占 |
