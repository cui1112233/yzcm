日期：2026-10-14

## 已完成

- 入口改为个人作品库：服务端 `Batch` 以两列封面架展示，小说只在打开作品后出现。
- 作品内增加顶部横向书轨道和小说列表；一本书是一个生产单位，不为每个视频任务堆叠卡片。
- 当前书增加原文、人物与场景、分镜与视频、合成与发布四个工作区。
- 小程序页面状态固定为 `works -> create -> project -> book`，返回路径为 `book -> project -> works`。
- 书城不再以 `2`/`番茄付费`作为默认事实；导入打开时读取公网配置，目录不可用时阻止立即/定时执行。
- 单书视频提交使用已确认的 V11 路由 `/api/batch-factory/v11/batches/{batchId}/books/{bookId}/production`。
- 能力门禁使用 `production.submit`、`director.run`、`merge.run`；缺能力或服务端拒绝时按钮禁用并显示原因。
