# 一战晟铭 · Mac 临时局域网版

适合 M4 等 Apple Silicon Mac。程序同时带 Apple Silicon 与 Intel 两种可执行文件，启动时自动选择；首次环境安装主要面向 macOS 15 或更新版本的 Apple Silicon。旧版 Intel/macOS 的依赖安装支持需要另行确认。此包不需要 Go、Node 或 Python。

## 第一次使用

1. 将整个 ZIP 解压到 Mac 的个人目录，建议文件夹命名为 `YZCM-LAN`。不要只复制其中一个程序文件，也不要直接在压缩包内启动。
2. 若尚未安装 Homebrew，先打开 https://brew.sh/ ，按官网安装说明完成安装。不要从其他网站复制安装命令。官方安装说明：https://docs.brew.sh/Installation 。
3. 打开 `首次安装.command`，安装原生 MySQL 8.4、Redis 和 FFmpeg；安装完成后打开 `启动.command`。这一步需要联网，依赖安装耗时由网络决定。
4. 启动成功后会自动打开本机页面，并显示类似 `http://192.168.x.x:4001` 的地址。同一局域网的同事打开显示的地址，使用线上原账号、原密码登录。若 Mac 询问是否允许局域网入站连接，请允许该程序。

如果 macOS 不允许双击 `.command`，可在“终端”输入 `bash `（最后有空格），将相应 `.command` 文件拖入终端，再按回车。这仅运行自己这份运行包，不需要关闭系统安全保护。

此版本没有 Apple 开发者公证。启动入口只会移除本包所选主程序的下载隔离标记，不会关闭系统 Gatekeeper 或修改其他应用。

## 哪些数据跟过来了

包含打包时线上账号的密码验证数据、启用/停用状态、团队关系、原有 MFA 设置、系统和用户 API/预设配置。密码没有被重置，也没有导出明文密码。已有浏览器登录状态不会迁移，第一次需要重新登录。

不会迁移线上正在执行的任务、任务队列、作品、历史正文或收费调用记录。新创建的作品和任务保存在这台 Mac 上，线上不会自动显示。账号、改密、停用及配置也是快照，之后不会自动跟随线上变化。

## 临时使用期间

- 作为主机的 Mac 要保持开机、联网且不进入睡眠。仅这台 Mac 安装运行包，同事的电脑只需要浏览器。
- 临时期间把新生产任务统一提交到局域网入口；不要将同一任务在两个入口各执行一次。两套程序的数据库和 Redis 各自独立，出图额度不会跨两套安装统一排队；原线上任务继续留在原站处理。
- 模型仍调用配置的网络 API；主要把排版、图片处理、应用运行和视频合成的工作转移到 Mac。此包不会改变模型价格，也不会自动扩容 YZCMAPI。
- 确认任务完成后打开 `停止.command`。若还有自动生产、图片请求、视频生产或合成任务，停止脚本会拒绝关闭，避免中途丢失结果。
- 之后可打开 `备份.command`，在 `backups/` 生成含本地数据库和文件的备份。保留整个运行目录和备份，迁回线上时需要做数据合并；不能直接拿本地数据库覆盖线上。
- 不要删除 `runtime/`、`data/` 或 `private/`；停止再启动不会重导入账号或清空作品。修改运行目录位置前先停止程序并保留完整目录。

## 主机保存须知

整个包包含账号密码验证数据及接口配置，只交给运行主机的管理者。不要发到群里、上传公开网盘或放入网站公开目录。线上 MySQL/Redis 密码、SSH 密钥、登录会话不在包内。数据库和队列只监听本机，局域网仅开放应用的 4001 端口。

## 需要排查时

日志：`runtime/logs/app.log`、`mysql.log`、`redis.log`。本机健康地址：`http://localhost:4001/health`。构建身份：`http://localhost:4001/api/runtime-build-info`。`snapshot.json` 说明账号快照时间与数量；`manifest.json` 记录文件校验值。

运行包在打包电脑上完成跨平台编译、数据库和登录保护验收；M4/macOS 原机首次启动仍需实际核验。构建固定在已核验的应用版本，并补上 Mac 磁盘空间检查；基础版本和补丁出处均记录在 manifest.json，不自动追随其他开发中的改动。
