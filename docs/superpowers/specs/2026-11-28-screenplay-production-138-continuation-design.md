# 138生产等待与明确续批

2026-11-28。属于已批准洛水剧本创作总计划D10的生产接通切片，不新增自动循环或付费授权。

- 沿用固定九步生产。138分镜使用当前作品已保存专业章节、现有回包保存服务；一批结果未完整时，保存等待状态，不进入分镜质检、视频或交付。
- `POST production/storyboard/continue`只接受原`request_key`和`confirmed`。服务端核对当前批次、原发起人及等待状态，生成固定下一批编号；同次确认重放不能再批准一批。
- 调用中、结果未知、取消或保存失败的请求只提供`POST production/storyboard/recover`。它核验已经返回的内容，不发送模型；没有合法回包时保留错误。完整回包恢复后，未暂停的全流程按原授权继续；暂停中的任务始终保持暂停，后续生产另需明确启动。
- 服务端冻结subject、team、实际actor和runID。当前切片仅接受subject为作品owner；共享非owner路径明确拒绝，不能从owner推测历史任务的实际操作者。模型发出前复核当前团队和资格，配置仍沿正式团队管理员解析。
- 普通批次更新不能覆盖冻结身份。新run与旧run通过持久runID及现有任务锁隔离；旧结果不得发布到新任务或推进新任务。
