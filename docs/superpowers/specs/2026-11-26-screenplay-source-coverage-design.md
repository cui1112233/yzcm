# 原文覆盖检查：实施设计

用户已确认按核账报告执行，本设计落实其中D04；其余工作包保持总计划待办。

保留现有镜头编号检查与seq补齐器，新增独立的来源覆盖核对，而不是把原文编号当镜头序号。显式原文编号、模型结果真实保存的source_elements/来源字段作为核对依据；原文无稳定编号或结果没有来源映射时，返回“来源未核验”，不猜测也不报告完整通过。允许一个原文元素被多个镜头共同使用时，不把这种拆镜天然当错误；重复需按原件语义及字段粒度准确区分并记录。

HTTP检查只读，按所选集绑定章节来源，不允许默认拿整部作品原文去检查一个集。报告保留既有结构字段，并添加独立来源状态、缺失/越界及来源基准。页面不把“编号连续”写成“原文完整”。现有自动补齐只能补镜头seq，来源缺口另行显示，防止把缺失原文编号误插到无关位置。

错误、跨用户权限、保存重读和版本保护沿用现有服务；检查不触发模型请求或扣费。先写尾部遗漏、未知来源、无映射、跨集、合法拆镜和seq补齐边界用例。具体字段以源码真实结构为准，不能为满足假测试制造未保存过的映射。没有来源证据的旧数据继续可用，但只能获得结构检查结论。

直接重写整套工作台会破坏已有能力；仅更换提示文案又不能查出遗漏，因此采用在现有结构检查旁增加独立来源核对的实现方式。
